# Stage 3 — 3D elements

Send this only after the background direction is approved.

Start with the highest-impact elements:

- main Kavvoro/brainball character;
- chaos portal/rift;
- classic and chaos platforms;
- boosts and hazards;
- glow, particles and decorative props.

Required delivery for every element:

- transparent PNG render, preferably at 2× resolution;
- source `.blend`, `.fbx` or `.glb`;
- textures;
- separate shadow/glow/particle passes where possible;
- front or intended game-camera render;
- a composition preview showing its intended placement.
