# Stage 4 — integration and code

Send this last, after the artist has delivered approved backgrounds and 3D elements.

This package contains the relevant Kotlin source, current editable Figma SVG exports and the Android visual asset folder.

At this stage the assets can be:

- placed into the Android resource pipeline;
- aligned against the 1080 × 2400 references;
- imported into Figma as separate layers;
- checked in the emulator against the existing UI.

The full repository still contains additional localized audio and build configuration; this staged package intentionally does not include those large files.
